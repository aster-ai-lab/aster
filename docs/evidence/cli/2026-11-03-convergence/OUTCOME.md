## Implemented behavior

- Collected the exact 35 original applications using actual native AIX builds,
  reconciled all 14 dependency/runtime identities and retained source hashes.
  Implementation, consumer and publication states remain separate in the ledger.
- Verified all 690 retained upstream files against the frozen commit's Git blob
  identities. All 14 original frozen contracts and their inputs remain unchanged.
- Ordinary plugin jobs persist in each tenant's capability directory. Restart
  recovery checks actual publication, selected version, artifact digest and
  runtime health. Interrupted jobs retain measured progress. Explicit retries
  bind the saved release and update the existing shared installation overlay.
- Successful use/install/exec explicitly track admitted configuration sources.
  Read-only loaders remain read-only. Pruning preserves global/tracked selections
  and running native/interpreted tools; previews preserve declarations, payloads
  and tracking. Native paths retain Unix bytes or Windows UTF-16 units.
- `tool upgrade` preserves configured ranges, supports explicit selectors,
  bump/pin/exclude/preview/offline and immediate previous-version pruning. It
  writes the owning parent/user/project file and uses the existing verified
  installer. Bad-checksum updates preserve that tool's prior executable, pointer
  and declaration. Installed activation verifies complete source-owned membership;
  offline preparation verifies all selected installations before activation.
  External path/system selections are skipped without inspecting their layouts.
- Repaired 42 required Pager Clippy errors in their owning sources without
  broadening lint allowances. Quoted provider labels retain Unicode characters.
