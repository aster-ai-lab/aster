# Core 与 ACP 文档补全计划

范围是当前工作树的 `a3s-code-core` 与 `a3s-code-acp` 9.1.6。保留已有 9.1.5 文章，不把当前接口覆盖结论套到旧版。

1. 以 `sdk_capabilities.rs` 的公开能力合同、ACP 的标准处理函数和 `HostMethod::parse` 的扩展集合建立索引。
2. 在 Core 的教程与 Meta Harness 专题之外，补配置、会话交互、工具、治理、检索、记忆、调度、高级宿主能力和运行排查。
3. ACP 独立成产品，补启动、协议生命周期、流式展示、模型、权限、插件、Office、目标、无人值守和扩展请求参考。
4. 每章写清入口、启用条件、操作步骤、结果判断和失败处理。能由现有教程解释的内容交叉链接，不用抽象口号替代用法。
5. 验证索引与当前源码集合一致、链接可达、版本隔离、图表和代码可读，以及桌面右下资料区与移动端布局。

覆盖索引证明每项公开合同有说明入口，不证明所有 feature、模型供应商或真实外部服务均已执行。示例整包编译、真实模型运行和性能数据分别记录，不混用结论。
