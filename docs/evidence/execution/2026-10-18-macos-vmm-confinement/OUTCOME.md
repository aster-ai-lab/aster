## 已验证

- VMM 在进入虚拟机前启用默认拒绝的 Seatbelt，仅授予已校验资产、私有运行目录、
  已绑定控制台和指定 Agent Unix socket 所需权限。
- Worker 清空继承环境，将 libkrun 的启动临时根目录放入该 VM 私有目录。
  缺少肯定隔离证据的旧 Shim 报告会被拒绝。
- 60 项 Shim 测试、18 项 Runtime 报告测试、严格 Clippy 和格式检查通过。
  测试中标为 ignored 的子入口由父测试在隔离子进程中实际调用。
- 干净源码和冻结候选通过真实 Host Service 生命周期、I/O/终端/文件操作、异常退出恢复、
  25 次循环与 25 个 VM 世代的验证。描述符保持 13，VM、端点和临时资源均完成回收。
- 在 28 个自有 Worker 中检查环境测试标记，未发现继承。原始环境未写入证据。

原始报告与构建摘要保存在本目录。重新构建的系统镜像和清单与此前保留的摘要一致。

## 尚未完成

Aster 默认 Bash 仍未接入这条 Runtime SDK 路径。还需完成带目录身份和权限的工作区传输、
SDK/宿主接入、命令镜像与网络策略、真实产品回归，以及发布资格验证。

已确认下一处上游限制：SDK 当前整体拒绝 caller-owned storage 与 runtime bundle handoff
组合，HVF 也尚未实现目录存储传输。下一阶段需一起解决所有权和挂载契约，验证删除只清理
Runtime 自有资源，并保留调用方工作区；不通过复制整个工作区或放宽宿主文件权限绕过。
