# 工作区目录授权与所有权移交

本次完成的是目录传输契约及移交、清理边界，不代表默认 Aster Bash 可用。

公共 SDK 为 `dev.a3s.bundle-handoff` 增加必选版本 2，对应固定注解
`move-to-runtime-v2`。外部存储仍为 Caller / DetachOnly。版本 1 继续拒绝
外部存储；未实现版本 2 的运行时会在移动目录前拒绝请求。通用扩展接口现在
同样验证已知版本的固定注解，不能绕过专用构建方法的语义校验。

运行时移交前、移交后及重放时均验证原始配置和授权。只有逐项授权的绝对
bind 源可留在包外，且必须为无路径别名的普通文件或目录，并与运行时控制
目录、共享目录不相交。清理只验证并删除运行时拥有的精确代次目录，不打开
外部挂载源；用户移动工作区后仍可正常清理。工作区内容和 0755 权限保留。

内部目录传输使用 `a3s.oci.agent-vm-attachments.v3`，绑定原始公共存储授权、
设备与 inode、源路径、访问模式和摘要派生的独立 virtio-fs 标签。重复挂载
索引、存储身份、源、inode 或标签均拒绝。没有目录时，现有 v1/v2 编码保持
兼容。当前 Guest 启动及 KVM Shim 明确拒绝尚未实现的目录传输，HVF 尚未
公布相关能力，因此不会默默忽略新的目录授权。
