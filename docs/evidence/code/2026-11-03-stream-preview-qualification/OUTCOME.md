# 流式用量与模型验证提示修复

两项独立红绿回归证明了共享路径缺陷。第一，Anthropic 协议的流式末帧可更新输入及缓存累计计数，原实现只读取首帧，后续实际输入可能被记为零。现在按字段替换累计值；缺失字段保留首帧，并复用现有 ObservedTokens 的检查和归一化，不相加、不增加计量器、不改变生成额度。

第二，模型输入只使用已有报告决定验证提示，最终完成判定却还会查询主机证明，导致当前文件已能由主机验证时仍提示缺少验证。现在复用同一完成门禁，使用主机显式选择加入的只读预览。旧宿主默认不参与预览，一次性最终回调不提前调用；预览报告不保存为最终证据，最终仍重新检查当前文件。磁盘回调在现有 blocking 任务池运行，取消不宣称能终止已经运行的同步回调。
