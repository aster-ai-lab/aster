# 已撤回：扩大摘要输入的候选

事实循环的摘要入口原先直接按工具输出保护额度裁剪，没有先判断完整摘要请求是否能放入模型窗口。一个可容纳的较早观察会在摘要模型看到它之前被删除；这与模型算错、提供方输出截断是不同问题。

现在先构造完整摘要请求，复用 estimate_prompt_tokens 计算系统指令和正文，并沿用原有约四分之一窗口的回复余量。能够容纳时完整交付观察；超出时继续使用原有工具输出裁剪。没有增加配置、依赖、调度器、计量器或每次压缩的模型调用，没有改变 provider 输出额度、摘要正文上限或义务封装。
