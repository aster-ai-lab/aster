# 主线长程循环的通用修复：真实任务整体验收仍未通过

本次将已有、尚未发布的观察进展机制按当前 main 的代码边界接入，修复三项独立复现的调度缺陷：重复拒绝仍进入输入准备、压缩清除重复额度、相同参数的新数据读取被误拦截。Core 继续使用原工具回执的观察摘要；Effect 与既有目标进展计数共用同一规范身份，未新增调度器、配置或模型调用。

文件日志保留最新摘要及其调度计数，并裁剪已被覆盖的旧摘要和准备记录。追加前先确认裁剪后确实容得下新记录；不足时原日志字节不变。回退到已被裁剪且没有对应摘要的历史会明确拒绝。累计约 48 MiB 输出、裁剪后重开以及工具额度一致性均由真实 FileLog 回归验证，未增加日志上限。

Anthropic 协议客户端复用现有 ObservedTokens，在 HTTP 与 SSE 路径将缓存输入计入完整 prompt，并保留缓存字段的缺失与显式零值。这符合[官方计数规则](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)。未更改摘要正文预算或 provider 生成上限，也未发布上一轮已撤回的摘要限额候选。
