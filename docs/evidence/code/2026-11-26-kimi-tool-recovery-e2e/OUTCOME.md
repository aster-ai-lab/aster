E06 exposed the remaining product gap. The pending state survived in original facts, while the public ACP load path restored transcript, modes and tooling without resuming the original host-input loop or declaring a Goal wait for the blocked step. Preserving that boundary prevented stale approvals from acquiring authority. Restoring the interaction requires fresh host authority bound to the original invocation or a freshly prepared one, plus an explicit persisted blocker. [ACP load path](../../../../crates/code/acp/src/agent/protocol.rs#L256)

E07 exposed a mismatch between tool admission and the existing completion rule. Receipt replay restores the unmatched prepared operation as unresolved. Before evaluating the next invocation, `prepare_tools_with_refusal` calls `settle_prior_turns`. That moves non-child uncertainty to goal-visible recorded debt and removes it from the active set read by the mutation gate. Hence the new write ran even though the old fact still lacked a terminal. The strict gate remains an explicitly run qualification case so the failure can be reproduced without changing prior-turn policy as part of this test campaign. [Preparation order](../../../../crates/code/core/src/fact_control/receipts.rs#L106) · [Uncertainty transition](../../../../crates/code/core/src/harness_loop.rs#L750)
