# 缺失用量时恢复已有压缩兜底

在 token 水位已开启的配置中，原实现把字符阈值改成 usize::MAX，且后续缺失用量时沿用较早的 prompt 计数。结果是提供方不报告用量时，两种压缩信号都不会生效。

保留调用者原有字符阈值，仅在当前模型响应缺失用量时回到该估算；有新鲜原生用量时，仍优先使用原生水位。后续缺失不再将旧的小 prompt 当成本次测量。没有增加配置、计量器或模型调用，没有将估算写成原生用量。公开方法签名不变，with_token_compact 文档更新以说明兜底行为。
