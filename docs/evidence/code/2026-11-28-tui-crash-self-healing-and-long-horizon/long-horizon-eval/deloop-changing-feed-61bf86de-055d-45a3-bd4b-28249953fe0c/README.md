feed.jsonl has one JSON header line followed by item JSON lines. Header: version, versions, currency, discount_bps, tax_bps. Each item has sku, quantity and unit_cents; description is provenance. Calculate each batch independently: units=sum quantities; subtotal_cents=sum(quantity*unit_cents); discount_cents=floor((subtotal_cents*discount_bps+5000)/10000); tax_cents=floor(((subtotal_cents-discount_cents)*tax_bps+5000)/10000); total_cents=subtotal_cents-discount_cents+tax_cents. All arithmetic uses integer cents. report.json must contain exactly batches and total_cents. batches is an array ordered by version 1..7, each with exactly version, units, subtotal_cents, discount_cents, tax_cents, total_cents. The outer total_cents sums all seven batch totals. Read all item lines. Source versions advance externally after each completed read; do not manufacture versions or edit sources. No intermediate writes; final report.json is the only writable file.
