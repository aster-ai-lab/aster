# 思考强度滑杆 UI/UX 修复

## 回退点

- 滑杆被限制在详情卡右列，轨道过短，难以辨认和操作。
- 默认档位的填充区间容易误读为已显式选择最低档。
- 轨道与交互区域过细。

## 修复

- 思考强度与滑杆改为详情卡内的整行布局。
- 滑杆交互区域由 28px 增加到 32px，轨道由 6px 增加到 8px。
- 仅当模型没有声明具体默认档位时，默认状态不绘制填充区间；声明默认档位时继续显示该档位。
- 保留拖拽、滚轮、键盘选择、ACP 档位约束和图片中的模型弹窗布局。
