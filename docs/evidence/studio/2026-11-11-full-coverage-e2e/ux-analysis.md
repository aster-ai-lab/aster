## 跨页面发现

1. **设置菜单选中态疑似与实际路由不同步**：`page-05`（快捷键）、`page-06`（用量）、`page-07`（模型服务）、`page-11`（数据）截图中，左侧菜单高亮始终停在「通用」，而主内容区已是对应子页。多张截图一致，不像单纯截图时机；但也可能是通过 AX `click` 导航时未触发路由侧的高亮更新。**标注为「疑似缺陷，需二次复核」**，不在本轮下结论。
2. **危险操作视觉分级不足**：数据页的「重置」「清除缓存」、归档页的清空类操作，与无害操作同权重。业界最佳实践（Material / HIG / Ant Design）要求破坏性操作用危险色 + 明确确认。这是本轮最明确的 UI 缺陷。
3. **正面**：技能页与连接器页共享同一套卡片/分类/分页结构；快捷键页的键帽表达；模型服务页的空态有明确下一步；用量页对「费用未知」不猜测填充。这些符合规范。
4. **未覆盖的视觉状态**：错误卡、工具轨迹、流式推理、产物加载、加载中浮层、键盘焦点环（需物理 `press`，本轮无 `--headed` 授权）、`prefers-reduced-motion` 开启态、真模型驱动的 222 项消息流形态。静态截图不评价动效时长与缓动。
5. **内部诊断扫描**：本轮 `pages` 阶段未发现 `completion gate` / `effect_digest` / `reasoning effort default` / `workspace mutation` 等技术标记；但扫描只覆盖 AX 的 `name/description/value`，设置页可见的绝对路径是合法配置展示，不能据「0 标记」推论「无任何内部细节」。
