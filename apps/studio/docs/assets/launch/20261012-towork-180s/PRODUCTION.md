# ToWork · 从任务到产物 · 180 秒制作计划

账号要求：用户指定账号，必须先在独立拍摄窗口登录并核验。登录界面、手机号、验证码和凭据不进入视频。当前素材状态：目标账号已通过真实滑块验证并登录，开始采集账号内页面。

## 概念候选

1. 从任务到产物：白色界面占主要画幅，固定近景与短距离跟随，任务产物成为前后章节的关联物。优先方案。
2. 能力装配台：浅灰舞台，能力详情与任务工作区在同一表面展开；安装后回到任务使用。
3. 团队协作之旅：从团队和消息进入任务，再完成产物与重复执行的设置。

本次沿真实操作组织画面，给任务对话及产物预览保留约一分钟。中文说明与原创配乐；结尾使用 ToWork 原始黑白标志。先输出 1080p30 可审阅版本。

## 参考测量

已分析 onetake 内置 clearing-15s：静止占比 29.4%，低运动占比 50%，最长静段 4.08 秒，动作 t80 中位数 0.44 秒。参考仅用于尺度连接与操作节奏；三分钟介绍需更长的阅读停留。分析输出保留在 `reference/` 和 `reference-analysis.log`。

## 验收

- 180.000 秒，1920×1080，30 fps，H.264 + AAC；完整音画解码通过。
- 每个列明功能都有真实截图及对应界面状态；安装和实际使用分别核验。
- 工作区与产物预览文字清楚，不以整页缩略图代替功能演示。
- 任意时间定位可重复，运动采样覆盖全部动画，关键内容取景检查通过。
- 成片没有登录凭据、完整手机号或未经筛选的私密消息。
- 原创或许可明确的声音；黑白标志与产品源文件一致。

登录已恢复：原生代理使用 API 公开的 admin captcha 路径，用户授权操作滑块后真实登录成功。登录画面不进入成片。

## 最终编排与已知限制

0–25 秒新建任务，25–46 秒技能安装与加载，46–93 秒 HTML／Markdown／CSV 产物，93–113 秒智能体安装和使用入口，113–131 秒连接器安装和调用请求，131–153 秒自动化配置和实际回答，153–160 秒消息，160–174 秒团队及角色，174–180 秒回到 ToWork 原始标志。

本次采用白色平面、绿色操作标记、左侧说明与右侧可读 UI 近景；短跟随落定后停留阅读，整个应用画框和操作指针贯穿各章节。未复用上一版的灰色漫游舞台。

智能体发送和 Fetch 实际调用未完成；CSV 表格预览编码、任务完成凭据绑定、自动化历史状态存在问题。成片明确标记相关限制，详细证据见 [QA.md](QA.md)。本轮不把产品缺陷改写为成功画面。
