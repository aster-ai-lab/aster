# ToWork · 工作台穿梭

120 秒中文产品介绍。用户指定“工作台穿梭”风格：同一个应用窗口留在浅灰工作表面上，镜头跟随操作指针，从侧栏进入能力详情，再回到任务对话与产物。结尾收拢为 ToWork 原始黑白标志。采用中文字幕与原创配乐。

素材全部来自本次会话中已经真实登录的指定账号（界面名 RoyLin）。复用当日 180 秒版本的原生采集证据，重新编排镜头、取景、时间线和声音；没有使用旧 120 秒版本的其他账号页面。登录、手机号、团队成员电话和插件页面不进入视频。

## 参考测量与视觉选择

旧 120 秒工作台漫游片只作为用户所选穿梭风格的运镜参考。分析输出在 `reference/`：静止 73.8%，低运动 82.9%，最长静段 9.5 秒；39 段移动，t80 中位数 0.64 秒，峰值 521 px/frame。新片保留尺度穿梭的语法，换为冷瓷灰舞台、墨绿黑文字、连续侧栏往返与真实任务产物主线。截图内容保持原样；任务草稿的输入揭示只遮罩原始文字。

## 真实性边界

技能安装及加载、文件生成与预览、智能体及 Fetch 安装、自动化创建及单次回答都有真实界面证据。智能体发送和 Fetch 调用没有成功完成，片中明确标记。自动化当前没有模板安装入口，因此演示创建、配置和运行，不虚构安装流程。任务完成、CSV 表格编码及自动化历史状态的已知问题保留在 [QA.md](QA.md)。

## 制作与验收

`film.html` 使用 onetake `motion.js` 的 camera、morphRect、cursor 和确定性曲线。`look.js` 嵌入许可字体。`score.py` 生成原创配乐及同一混响空间中的合成音效。1080p30 帧渲染采用真实快门运动模糊。

验收包含全部 3601 个定位时刻、关键取景边界、重复定位像素一致性、原始截图哈希、Logo 源文件一致性、编码参数、完整音画解码和编码后关键帧检查。检查结果与成片一同保留。
