## 保留的产品缺陷

1. 文件写入成功，但任务完成时缺少绑定到写入的验证凭据，运行未正常结束；后续内容核对不能代替该绑定。
2. 法务专家在 @ 选入后发送失败；没有拼接或重写专家回答。
3. Fetch 调用未完成；安装状态不能证明实际网页抓取成功。
4. CSV 源文件中文正确，表格预览有乱码；本片展示真实源码视图。
5. 自动化会话已有回答，但运行历史仍显示运行中。
6. Markdown 宽表在原生编辑区右侧溢出，保留实际渲染。

## 成片验证

检查结果保留在 `composition-check.json`、`media-check.json`、`ffprobe.json`、`verify.log` 与 `encoded-sheet.jpg`。

- 120.000 秒、3600 帧、1920×1080、30 fps、H.264 + AAC 48 kHz 双声道；全片音画解码退出码为 0。
- 全部 3601 个定位时刻无异常、关键声明区域无出框；先跳到其他时刻再返回，像素哈希一致。
- 22 组使用素材都有原始哈希；未使用插件页或团队成员电话页；Logo 字节与产品源文件完全一致。
- 编码后抽取并目视检查 38 个时刻，覆盖全部功能、侧栏往返、产物及结尾。

- 连续性探针自动识别了 2 个边界，carry 为 1.00；其他路由衔接通过上述编码画面审阅核验。该分数不是所有产品流程的端到端通过率。
- 文档链接、目录结构和索引检查通过。Frontmatter 检查仍受既有文档问题阻塞：`docs/references/architecture/aix-ui-document-protocol.md` 引用了缺失的 `src-tauri/src/capabilities_vsix.rs`；本次没有修改该文档。
