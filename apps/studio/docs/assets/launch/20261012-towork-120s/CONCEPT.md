# ToWork · 工作台漫游 · 120 秒

用户选择方案 2。一个真实工作台、一条操作线、一台跟随操作的镜头。浅灰底、白色工作面、黑白品牌，中文说明配原创音乐与触感音效。不开启插件页面。

参考研究：onetake clearing-15s。静止占比 29.4%，最长安静画面 4.08 秒，运动 t80 中位数 0.44，峰值约 129 px/frame。借鉴接近对象、阅读、拉远的尺度变化；本片是两分钟功能漫游，不复制短参考的硬切连击和蓝色美术。

素材来自独立的 `just fork towork-cua` 原生窗口，AX 状态与 PNG 同名保存。回答来自一次实际完成的模型任务。知识笔记是已有测试样本，仅阅读和切换视图；未改写其内容。自动化草稿已取消，未保存、未启用。

制作采用原始界面截图、输入区域逐步揭示、组件局部合成和确定性镜头。重建指针用于说明点击因果。分屏工具栏与知识首页补拍后，使用相同状态下的真实组件像素合成，去掉重复原生指针。局部合成仅处理指针残影、菜单开合和输入揭示，不生成产品结果。

品牌使用 `src/renderer/assets/images/logo.png` 的原始黑白 ToWork 图标。租户目录里的红色 TOYOU 标志属于公司品牌，不用于本片。
