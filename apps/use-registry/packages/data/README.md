# 数据

AsterDream 的数据插件。首页输入框增加「数据分析」工作模式，插件可以在独立系统窗口打开，活动栏菜单由成员在插件设置里决定是否添加。

页面按数据库工作台排列：左侧是连接和表，上方是 SQL 编辑器，下方是带行号的结果网格。可以保存 SQLite 或 PostgreSQL 连接和数据源，点开一张表或运行一条 SQL。数据分析模式用同一套编辑器和网格查询已保存的数据源，并显示这些行里的数值合计。

安装：把本目录打成 `.aix` 后发布到插件目录，或由 AsterDream 作为一等包挂上首页工作模式和独立窗口。活动栏菜单在插件设置里打开。SQL 由 a3s-orm 的 SQLite 与 PostgreSQL 驱动在 AsterDream 宿主里执行。页面提交引擎和连接目标。
