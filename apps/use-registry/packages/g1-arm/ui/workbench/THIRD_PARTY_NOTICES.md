## Unitree G1 (MuJoCo Menagerie)

- Source: MuJoCo Menagerie `unitree_g1` (`g1_with_hands.xml` and `assets/*.STL`), as carried by the EmbodiedJev Unitree G1 integration package (`assets/g1/`).
- Copyright (c) 2016-2023 HangZhou YuShu TECHNOLOGY CO.,LTD. ("Unitree Robotics").
- License: BSD-3-Clause. The full text is `vendor/g1/LICENSE`.
- `vendor/g1/g1.js` is **modified** and generated by `tools/vendor-g1.mjs`:
  - `g1_with_hands.xml` (SHA-256 `2d41a3c6783fbf9e17349608d9c2222d970163b1db315ce9f30c4a97631fc078`): model renamed, `meshdir` removed, timestep 0.002, keyframe removed, pelvis freejoint removed and the pelvis welded at the table edge, geoms of the pelvis, legs, left arm and left hand removed (their inertials kept), the right Dex3-1 hand and its actuators replaced by the Panda hand below, right arm and waist pitch servo gain 1500, visual geoms removed from the physics model, and a marker added where the task scene is inserted.
  - Each remaining G1 collision mesh is replaced by the vertices of its convex hull, inline in the model. MuJoCo collides against the hull, and the vendor tool checks that MuJoCo builds the same hull from them.
  - The visual meshes are drawn by three.js instead. Their vertices are quantized to 16 bits per axis over each mesh's bounding box and packed with their indices.
  - Everything is gzip-compressed and base64-encoded in one module.

## MuJoCo 3.15.0

- Source: npm package [`@mujoco/mujoco@3.15.0`](https://www.npmjs.com/package/@mujoco/mujoco), built from [google-deepmind/mujoco `wasm/`](https://github.com/google-deepmind/mujoco/tree/main/wasm).
- Copyright: Google DeepMind.
- License: Apache-2.0. The full text is `vendor/mujoco/LICENSE`.
- Included: the single-threaded build.
  - `mujoco.wasm` is unmodified. It is carried gzip-compressed and base64-encoded in `vendor/mujoco/wasm.js`; `engine.js` restores the original bytes.
  - `vendor/mujoco/mujoco.js` is **modified**. The upstream file generates embind invokers with `new Function`, which the Desktop view policy refuses. Two generators (`craftInvokerFunction` and `__emval_get_method_caller`) are replaced with closures that make the same calls in the same order, as Emscripten's `DYNAMIC_EXECUTION=0` build does. Each change is marked `// a3s patch:`. `tools/vendor-mujoco.mjs` in the package source applies the patch to the upstream file.
