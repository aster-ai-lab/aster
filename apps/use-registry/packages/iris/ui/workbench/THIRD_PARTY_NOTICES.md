## 3DR Iris meshes (PX4 SITL Gazebo Classic)

- Source: [PX4/PX4-SITL_gazebo-classic](https://github.com/PX4/PX4-SITL_gazebo-classic) `models/iris` meshes (`iris.stl`, `iris_prop_ccw.stl`, `iris_prop_cw.stl`), as carried by the EmbodiedJev Iris integration.
- The upstream `package.xml` declares `<license>BSD</license>`. That file is `vendor/iris/LICENSE`. The upstream repository publishes no separate LICENSE text, so this package does not add one. The integration note calls the meshes BSD-3-Clause.
- `vendor/iris/iris.js` is **modified** and generated by `tools/vendor-iris.mjs`. Vertices are quantized to 16 bits over each mesh's bounding box, then gzip-compressed and base64-encoded. three.js draws them. The physics model collides with a box, not these meshes.

## MuJoCo 3.15.0

- Source: npm package [`@mujoco/mujoco@3.15.0`](https://www.npmjs.com/package/@mujoco/mujoco), built from [google-deepmind/mujoco `wasm/`](https://github.com/google-deepmind/mujoco/tree/main/wasm).
- Copyright: Google DeepMind.
- License: Apache-2.0. The full text is `vendor/mujoco/LICENSE`.
- Included: the single-threaded build.
  - `mujoco.wasm` is unmodified. It is carried gzip-compressed and base64-encoded in `vendor/mujoco/wasm.js`; `engine.js` restores the original bytes.
  - `vendor/mujoco/mujoco.js` is **modified**. The upstream file generates embind invokers with `new Function`, which the Desktop view policy refuses. Two generators (`craftInvokerFunction` and `__emval_get_method_caller`) are replaced with closures that make the same calls in the same order, as Emscripten's `DYNAMIC_EXECUTION=0` build does. Each change is marked `// a3s patch:`. The patch is the same file shipped by `a3s/g1-arm`.
