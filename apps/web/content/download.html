开始一项任务

选好项目，说明目标，确认需要的权限，再查看结果。

  1. 选择项目文件夹

    选择本地项目目录，确认当前工作区的信任设置。

  2. 说明要做什么

    写清目标、允许修改的范围，以及希望怎样检查结果。

  3. 确认需要的权限

    工具按当前权限设置执行。需要确认的操作会等你回复。

  4. 按需开启审查

    需要复核时，开启独立审查，检查回复、工具结果和生成文件。

  5. 查看文件与记录

    需要追溯时，可开启文件快照，回看来源、版本和执行记录。

还有想确认的？

Aster 是什么？

Aster 是基于 Rust 的智能体执行内核与编程工具。桌面版提供可视化的本地工作台，CLI 提供终端交互。它连接你配置的模型，在项目中读取文件、修改内容并调用工具。

需要注册账号或订阅吗？

Aster 本地版无需注册 Aster 账号。你需要自行配置模型服务及对应的访问凭据；模型服务可能由服务商收费，请以你选择的服务为准。

支持哪些系统？

当前公开桌面安装包仅有 macOS Apple Silicon；Windows 与 Linux 桌面版敬请期待。CLI 提供 macOS、Linux x86_64 / arm64 和 Windows 归档。请在下载弹层中核对版本与架构，其他平台的支持以实际发行说明为准。

网站里的应用画面是真实界面吗？

是。截图由实际 Aster 界面运行后采集，使用独立的演示项目、文档与记录。网页只展示截图，不会运行 Office、调用模型或访问你的文件；截图中的数据与审查状态不代表你的真实任务结果。

下载后的界面会和截图完全相同吗？

截图展示当前开发版本的界面。下载弹层标明当前公开稳定安装包的版本与架构，可能早于截图。请查看发行说明确认具体变化，并按开始使用文档配置模型。

桌面版和 CLI 是两套东西吗？

不是。两者共用同一个 Rust 智能体执行内核，权限策略、事实日志与完成条件的判定方式一致。区别只是入口：桌面版提供可视化工作台，CLI 在终端里工作。
