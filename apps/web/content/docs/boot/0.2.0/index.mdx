`a3s-boot` 是模块化 Rust 异步服务框架。当前版本为 `0.2.0`。模块组织应用，Provider 提供依赖，Controller 暴露路由，协议中立管线处理请求。

Boot 不是 Axum 包装器。请求、响应、路由和执行上下文属于 Boot 核心。Axum 是默认 HTTP 适配器。

属性宏在编译期生成普通 Boot 定义。动态注册仍使用显式 Builder API，不依赖运行时 decorator 元数据。

## Feature 边界

默认 feature 是 `axum`、`macros` 和 `shutdown-hooks`。其他集成按需启用。

<DocTable caption="常用可选 Feature" headers={['领域', 'Feature', '说明']} rows={[
  ['配置与安全', 'config、auth、security、session', 'ACL、认证、安全策略和会话抽象'],
  ['数据与任务', 'database、cache、queue、queue-postgres', '后端抽象与 PostgreSQL 持久队列'],
  ['事件与调度', 'events、cqrs、schedule', '事件、命令查询和定时任务'],
  ['协议', 'tcp、redis、nats、mqtt、rabbitmq、kafka、grpc 对应 feature', '共享 MessageTransport 合同'],
  ['HTTP 辅助', 'openapi-schemas、file-upload、static、compression', 'Schema、上传、静态文件和压缩'],
]} />

Feature 只暴露对应集成。Database、Cache、Session 和 Queue 抽象不代表所有生产后端都已交付。
