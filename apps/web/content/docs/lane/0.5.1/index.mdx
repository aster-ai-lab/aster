`a3s-lane` 是异步任务的优先级队列与调度库。当前版本为 `0.5.1`。它支持命名 Lane、每 Lane 并发限制、重试、超时、DLQ、事件和指标。

Priority 决定下一个获准执行的等待项，不会中断已经运行的 Future。活动工作需要显式取消和结算合同。

相同 Priority 的任务保持 FIFO。自定义 Lane 可以替换或扩展默认配置。Rate Limit 在 Dequeue 时执行，不是在 Submit 时执行。

`PriorityQueue<T>` 的 `restore()` 可以恢复准入失败的原始 FIFO 位置。`ordered()` 只提供队列视图，不修改顺序。

## Feature 与演进状态

默认 feature 是 `metrics`、`monitoring`、`telemetry` 和 `distributed`。关闭默认 feature 可以只使用核心队列。`redis-backend` 是可选的多进程 Job Backend。

Lane Scheduler 已提供完整的优先级和并发控制。通用 Job Runtime、Job 管理 API、Worker、Flow 和 Repeat 仍在持续演进，不能把所有后端能力视为同一发布承诺。

PostgreSQL 与 NATS Job Backend 仍在计划中。
