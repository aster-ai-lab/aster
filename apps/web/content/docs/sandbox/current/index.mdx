Aster Sandbox 包含两个独立组件。`a3s-sandbox` 限制不可信命令的进程树。`a3s-box` 创建并管理基于 OCI 镜像的 Sandbox。

两个组件不是同一接口的两个名称。它们解决的问题不同，也不互相替代。

## 隔离方式

`a3s-sandbox` 使用宿主操作系统的原生隔离机制。默认策略拒绝网络和宿主 Unix-domain socket，并限制写入范围。

`a3s-box` 默认使用 MicroVM。共享内核 Sandbox 是显式选项，只适用于满足要求的 Linux 主机。命名桥接网络和端口发布仅由 MicroVM 支持。
