`a3s-event` 是 Provider 中立的发布、订阅和持久化库。当前版本为 `0.4.0`。应用通过 `EventBus` 和 `EventProvider` 使用统一接口。

Memory、NATS JetStream 和 Apache Iggy 后端共享事件 Envelope 与订阅合同，但不共享全部投递控制或历史顺序。

默认 feature 是 `iggy`、`encryption`、`cloudevents` 和 `routing`。最小核心关闭默认 feature 后，只保留类型、MemoryProvider、EventBus、Schema、DLQ 和 Metrics。

## 统一事件模型

Event Envelope 包含 ID、Subject、Category、Event Type、Version 和 Payload。投递上下文包含 Sequence、Num Delivered 和 Stream。

Subject 使用点分层次：

```text
events.<category>.<topic>[.<subtopic>...]
```

通配符 `events.market.>` 匹配任意深度的 Market 事件，`events.*.forex` 匹配任意 Category 下的 Forex 主题。

Schema Registry、DLQ、StateStore 和 Metrics 属于 Event。重试、Backpressure、连接恢复和分区仍由 Provider 或宿主负责。

## 当前限制

Iggy 目前拒绝 `expected_sequence` 和 `DeliverPolicy::LastPerSubject`。部分重投递参数会被接受但忽略，Topic 也只有单分区。

Iggy Server 的上游重启缺陷仍可能阻止相同数据目录再次启动。当前 `iggy` feature 不能标记为 GA-hardened，生产采用前必须核对上游修复。

不同 Provider 的历史顺序不属于统一合同。Memory 为 newest-first，Broker 通常为 oldest-first。
