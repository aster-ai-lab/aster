`a3s-apofasi` 是类型化 System-1 决策引擎。宿主提供状态和类型化问题，Apofasi 返回 `choice`、`score` 或 `noul` 答案。

它不生成自由文本，也不要求宿主解析模型输出。当前版本为 `0.1.1`。

## 决策边界

<DocTable caption="Apofasi 的决策类型" headers={['类型', '问题配置', '返回内容']} rows={[
  ['choice', '选项到说明的映射', '选项、概率与 confidence'],

`choice` 和 `score` 使用 confidence 辅助门禁。`noul` 使用概率接近 0 或 1 的程度作为信号。阈值和人工复核策略由宿主决定。

## 两种执行路径

<DocTable caption="Apofasi 的执行路径" headers={['路径', '启用方式', '依赖与用途']} rows={[
  ['词法引擎', '默认', '无权重和 ML framework，提供轻量类型表面与路由'],
  ['神经推理', 'infer feature', '加载 checkpoint，执行 encoder 与决策头'],
]} />

默认构建只启用 `router`。神经推理、Metal、MLX、CUDA、训练和 CLI 都是显式 feature。

## 产品边界

Apofasi 负责类型化决策、校准和 checkpoint 路由。宿主决定何时调用、何时升级人工复核，以及如何安装运行环境。

A3S Flow 负责多步工作流，A3S Use 负责能力包，Aster Code 的模型路径负责生成式回答。Apofasi 不替代这些组件。
