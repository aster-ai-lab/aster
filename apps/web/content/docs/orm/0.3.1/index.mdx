`a3s-orm` 是类型安全、Executor 中立的 Rust SQL 查询构建器。当前版本为 `0.3.1`，要求 Rust 1.85 或更新版本。

表声明在编译期约束列、值、赋值和查询结果。不可变 Builder 生成 SQL 与绑定参数，再通过异步 Executor 执行。

ORM 不是 Active Record 框架。记录不拥有持久化行为，查询保持可见，运行时值不会插值到 SQL 文本中。

默认 feature 是 `sqlite`。`postgres` 启用 UUID、JSON、Chrono、Decimal、数组和 Deadpool 驱动。关闭默认 feature 可以只使用查询构建和方言编译。

## 主要边界

SQLite 内置 Executor 在单连接上串行执行，不是多连接池。MySQL 只表示 SQL 生成，不表示已有运行时驱动。

迁移只向前执行。类型化 DDL Builder、查询插件、自定义 PostgreSQL domain codec 和 Schema 代码生成尚未包含。
