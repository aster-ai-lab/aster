`a3s-gateway` 是本地流量数据平面。它位于客户端与模型或 HTTP 后端之间，负责请求准入、路由、健康选择和流式响应。

Gateway 不负责租户、人工运维界面、模型训练或长期计费账本。当前源码版本为 `1.1.1`。

## 部署模式

<DocTable caption="Gateway 的两种部署模式" headers={['模式', '期望状态所有者', 'Gateway 职责']} rows={[
  ['standalone', '本地操作员与 ACL', '校验并执行路由、中间件、提供方、健康、修订权重和可选扩缩'],
  ['cloud-managed', 'A3S Cloud', '校验并执行绑定身份、修订、摘要、CAS 和过期的完整快照'],
]} />

更改部署模式需要重启进程。Gateway 在本地执行流量决策，不要求每个请求都经过 Cloud。
