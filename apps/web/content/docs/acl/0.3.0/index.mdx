`a3s-acl` 提供 Agent Configuration Language 的解析器、生成器和结构校验。当前源码版本为 `0.3.0`。Aster 用 ACL 描述模型、工具和宿主配置；具体字段与生效规则由消费该配置的组件声明。

ACL 不是权限控制表的缩写。解析一份 ACL 文本，只表示语法和数据结构可读取，不表示其中的操作已获得授权。

## 文档、块与值

```acl
providers "example" {
  api_key = env("EXAMPLE_API_KEY")
  models = ["example-model"]
}
```

`providers` 是块名，`"example"` 是标签，`api_key` 与 `models` 是属性。块可以嵌套，属性值可以是字符串、数字、布尔、列表、对象、null 或函数调用。

解析结果使用 `Document`、`Block` 和 `Value`。`env("EXAMPLE_API_KEY")` 保留为 `Value::Call`，解析器不会因此读取环境变量。是否允许该调用、从哪里取值、是否可以激活配置，都由宿主决定。见 <SourceRef path="crates/acl/src/ast.rs" match="Call(String, Vec<Value>),">函数调用的 AST 表示</SourceRef>。
