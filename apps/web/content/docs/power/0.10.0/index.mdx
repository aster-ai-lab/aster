`a3s-power` 是模型中立的 Rust 推理执行层。Power 为模型 crate 提供制品身份、设备放置、请求准入、取消、有界状态和执行回执。

当前版本为 `0.10.0`。该版本属于 pre-v1，尚未通过生产版 v1 的完整证据门。

## 职责边界

Power 核心不按模型家族分派执行。模型 crate 保留模型语义，Power 管理共享执行边界。

  ['Cloud', '副本、放置、部署代际和快照', '不处理每个请求的同步转发'],
]} />

Power 提供 CPU、CUDA 和 Metal 执行边界。具体后端、模型和硬件仍需分别验证。

## 当前发布状态

strict v1 证据门要求 CPU、CUDA、Metal 和 confidential GPU 四类捕获。当前缺少同一冻结父提交的 Metal 与 SEV-SNP confidential GPU 证据。

因此，`0.10.0` 不是生产版 v1 的替代品。`v1.0.0` 尚未作为生产版本发布。
