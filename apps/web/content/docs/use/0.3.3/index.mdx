`a3s-use` 是 AI Native Package Manager 和本机能力宿主。当前主包版本为 `0.3.3`，要求 Rust 1.85 或更新版本。

Use 安装、升级和卸载扩展包，并通过审查后的计划启用能力。`.aix` 是当前原生包格式，使用 ACL manifest 描述包身份、版本和扩展表面。

## 信任与宿主边界

Use 校验包结构、manifest、文件清单、摘要和 Registry 目标身份。宿主仍负责工作区授权、秘密管理、进程生命周期和最终启用决定。

本地 `.aix` 的 Schema 校验不代替 Registry 信任验证。Registry 使用 TUF 元数据、签名目录证据和目标摘要建立发布边界。

`actions` 声明包可能请求的读、修改和执行能力。应用计划前必须审查这些声明、工具入口和外部依赖。
