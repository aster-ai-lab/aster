## 这份索引覆盖什么

本页逐项列出当前 `sdk_capabilities()` 中的 30 项公开合同，并保留规范操作名。点击用法进入对应章节；展开“规范操作”可对照 Rust 合同定位。

baseline 是基础能力合同，advanced 是可选或宿主专用能力，并不表示当前 Session 一定能执行。运行时可用性应以工具投影、provider 状态和类型化拒绝判断。
