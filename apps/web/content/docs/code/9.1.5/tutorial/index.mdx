## 教程产物

教程从空的 Rust 宿主开始，实现 `tutorial-agent` 终端编码助手。程序接收任务，显示模型回复和工具进度，处理操作确认，检查修改结果，并在退出后恢复会话。程序使用 Aster Code 的 Rust SDK，Core 负责模型推理、工具执行和事实日志。

各章持续修改 `apps/tutorial-agent`。先实现只读任务，再加入写入和执行权限。完成基础界面后，按需求接入后续能力。未配置的外部服务仍需单独配置。

## 先决条件

开始前，确认能阅读 Rust 的 `async`、`Result` 和 `Arc`，并准备一份可连接模型的可信 ACL 配置。所有 Cargo 命令都在本仓库根目录执行，沿用根工作区、锁文件和固定 Rust 工具链。练习包使用本地 `a3s-code-core`，不从包仓库安装另一个 SDK。

终端界面使用工作区已有的 Ratatui 和 Crossterm。教程给出文件名和代码。需要替换 `main.rs` 时会明确说明，后续函数接入前面建好的运行层。

示例中的 `use` 合并到对应模块顶部，已有导入不必重复添加。第四章开始，运行层保留一个 `Runtime`，统一持有 Agent、会话和确认通道。后续存储与扩展继续接入这个对象。
