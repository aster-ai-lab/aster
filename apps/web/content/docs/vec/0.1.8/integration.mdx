Vec 以 `Collection` 为工作单元。Schema 决定字段类型、向量维度、距离度量和索引参数。写入与查询都按 Schema 校验。

## 创建 Collection 并查询向量

```rust
use a3s_vec::{
    Collection, CollectionSchema, DataType, Doc, FieldSchema, IndexParams,
    MetricType, Result, SearchQuery,
};

fn main() -> Result<()> {
    let schema = CollectionSchema::builder("workspace")
        .add_field(FieldSchema::new("title", DataType::String, true, 0)?)
        .add_vector_field(
            "embedding",
            DataType::VectorFp32,
            4,
            IndexParams::hnsw(MetricType::Cosine, 16, 100)?,
        )
        .build()?;

    let collection = Collection::create_and_open("./workspace-index", &schema, None)?;
    let mut doc = Doc::with_pk("src/lib.rs")?;
    doc.add_string("title", "Vector retrieval")?;
    doc.add_vector_f32("embedding", &[0.1, 0.2, 0.3, 0.4])?;
    collection.insert(&[&doc])?;

    let hits = collection.query(&SearchQuery::new(
        "embedding",
        &[0.1, 0.2, 0.3, 0.4],
        1,
    )?)?;
    assert_eq!(hits[0].get_pk(), Some("src/lib.rs"));

    collection.close()?;
    let _ = std::fs::remove_dir_all("./workspace-index");
    Ok(())
}
```

`create_and_open` 创建或打开持久集合。测试结束后删除练习目录，生产代码不要复用该目录。

## 全文查询

```rust
use a3s_vec::{Fts, SearchQuery};

let mut expression = Fts::new()?;
expression.set_query_string("rust AND \"vector database\"")?;
let hits = collection.query(&SearchQuery::fts("body", &expression, 10)?)?;
```

字段需要配置 FTS 索引。分词器支持 `standard`、`whitespace`、`ngram` 和可选 `jieba`。请求未启用的分词器会返回 `NotSupported`，不会替换为其他分词器。

## 异步接口

启用 `async` feature 后，`query_async`、multi-query 和 group-by 在 Tokio blocking pool 中执行。异步接口复用同步查询的规划、评分、回退和遥测语义。

不要为普通小集合默认创建独立异步运行时。先确定查询成本和现有宿主模型。

## 验收

1. 创建 Schema，验证字段类型和向量维度。
2. 插入、读取、更新和删除文档，核对每条写入结果。
3. 执行向量与全文查询，核对主键和分数顺序。
4. 使用错误维度查询，确认返回类型化错误。
5. 删除派生索引缓存后重新打开，确认精确回退仍返回正确结果。
