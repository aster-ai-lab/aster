`a3s-vec` 是进程内向量与全文检索库。调用方提供文档、向量和嵌入模型，Vec 负责存储、索引、查询和持久化。

当前版本为 `0.1.8`。库不需要独立数据库进程，也不依赖 C/C++ runtime。

## 产品边界

Vec 不提供嵌入模型，不启动模型下载，也不作为托管向量云服务。`a3s-code` 负责工作区检索适配和模型供应商策略。

Vec 不承诺 zvec 的 C++ ABI 或二进制存储兼容。公开 Rust API 使用 A3S 自有类型。
