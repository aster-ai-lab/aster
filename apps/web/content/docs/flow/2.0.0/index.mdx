`a3s-flow` 是持久工作流引擎和 Rust SDK，当前源码版本为 `2.0.0`。它通过追加式历史保存步骤、等待、重试、子工作流和终态，在进程重启或 Worker 替换后重新投影状态。

Flow 适合跨多次调度、需要等待审批或外部事件的任务。纯内存排队不需要承担完整工作流历史时，可先了解 [Lane](../../lane/0.5.1/)；需要理解智能体 Harness 的事实折叠，可阅读 [Effect](../../effect/0.2.1/)。

## 决策与操作分开

`FlowRuntime::run_workflow` 读取历史投影并返回下一条确定性 `RuntimeCommand`。外部访问放在 `run_step` 或 `run_activity`，不要在每次重放的决策函数里直接调用工具、网络或模型。见 <SourceRef path="crates/flow/src/runtime.rs" match="pub trait FlowRuntime: Send + Sync">运行时接口</SourceRef>。

已提交的步骤结果可以重放。相同步骤身份对应的输入、策略或等待条件发生漂移时，引擎拒绝非确定性重放，不会把它解释成同一次操作。

## 与宿主的边界

Flow 管理工作流历史和生命周期。宿主负责身份、授权、租户隔离、凭据、可用节点与工具、业务发布和调度资源。一个工作流图通过结构检查，不表示其中的节点已获得执行许可。

外部副作用的物理边界是**至少一次**。如果操作已经成功，但结果尚未持久化时进程退出，恢复后可能再次执行。Flow 的持久历史不等于外部系统中的恰好一次效果。
