最佳使用方式

五个步骤，把事情做完

Aster 的默认节奏：从授权到验收，每一步都留有依据。

  1. 01

    选择项目文件夹

    只在你授权的目录里工作，宿主与工作区的信任边界保持清晰。

  2. 02

    先看计划再执行

    计划先交给你审阅，需要确认的动作停下来等你回答再继续。

  3. 03

    按权限调用工具

    每次工具调用都过一遍权限判定，拒绝的动作不会悄悄发生。

  4. 04

    完成后自动审查

    让模型另起一次独立检查，核对回复、工具结果与产物。

  5. 05

    交付即有据可查

    产物保留来源、版本与执行记录，随时回看它是怎么来的。

常见问题

还有想确认的？

Aster 是什么？

Aster 是基于 Rust 的智能体执行内核与编程工具。桌面版提供可视化的本地工作台，CLI 提供终端交互。它连接你配置的模型，在项目中读取文件、修改内容并调用工具。

需要注册账号或订阅吗？

Aster 本地版无需注册 Aster 账号。你需要自行配置模型服务及对应的访问凭据；模型服务可能由服务商收费，请以你选择的服务为准。

支持哪些系统？

当前公开桌面安装包包括 macOS Apple Silicon、Windows x64 和Linux x86_64；CLI 提供 macOS、Linux 和 Windows 归档。请在下载弹层中核对版本与架构，其他平台的支持以实际发行说明为准。

网站里的应用画面是真实界面吗？

是。截图由实际 Aster 界面运行后采集，使用独立的演示项目、文档与记录。网页只展示截图，不会运行 Office、调用模型或访问你的文件；截图中的数据与审查状态不代表你的真实任务结果。

下载后的界面会和截图完全相同吗？

截图展示当前开发版本的界面。下载弹层标明当前公开稳定安装包的版本与架构，可能早于截图。请查看发行说明确认具体变化，并按开始使用文档配置模型。

桌面版和 CLI 是两套东西吗？

不是。两者共用同一个 Rust 智能体执行内核，权限策略、事实日志与完成条件的判定方式一致。区别只是入口：桌面版提供可视化工作台，CLI 在终端里工作。
