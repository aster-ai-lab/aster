ASTER ACP / 01

把 Aster 接进自己的客户端

先理解进程与协议边界，再接入模型、会话和宿主扩展。

Aster ACP 9.1.6 · 当前源码·2026-10-26

ACP 负责哪一层

a3s-code-acp 是运行在独立进程中的 Agent Client Protocol 代理。客户端负责界面、启动进程、请求权限和接收更新；代理把协议请求接到 Core，执行模型调用、受控工具与会话持久化。

Core 和 ACP 使用相同的运行时，并不具有完全相同的接口。Rust 宿主可以注入 trait 实现和组件树；ACP 客户端只能选择代理明确提供的协议与宿主扩展。提交一个组件名称不会让代理动态加载任意 Rust 代码。

建议的接入顺序

  1. 配置可信 ACL，构建并启动配套的终端与 ACP。
  2. 完成 initialize、session/new、一次只读 session/prompt 和 session/cancel。
  3. 接入流式文本、工具状态、权限请求和业务问题，检查取消后的终态。
  4. 接入会话保存与加载、模型选择和工具目录。
  5. 按产品需要启用插件、Office、长期目标或无人值守；逐项验收。

下面的章节介绍这一步步怎样做。JSON 示例都是线上协议消息或工具参数，不是配置文件。源码中的闭集字段和 schema 才是消息兼容性的依据。

版本与交付

本组文档对应当前仓库 9.1.6 源码。aster 与 a3s-code-acp 必须配套构建、分发；不要把任意上游发行包覆盖到 Aster 安装中。源码引用当前指向 main，工作树未提交的改动不一定已经出现在远程。
