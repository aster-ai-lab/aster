合同之外的配套说明

权限确认、业务表单、Hooks、Run 资源、目录 Agent、工作策略、长期目标、会话审阅、轨迹采集、结果账本和内容转换也属于接入工作。它们分别见治理、任务调度、高级宿主、故障排查与 Meta Harness 章节。

按任务阅读

01选择构建能力，再给会话接入模型构建 profile、ACL 信任层、模型适配器与超时边界。↗02处理追加指令、提问和取消Run 回执、并发控制、确认队列和用户回答的区别。↗03选择工具，并保留调用结果的边界内置工具、后台任务、批量操作、大输出与宿主工具。↗04把检查放在真正执行的位置权限层、沙箱、确认、Hook、预算和完成证据的接线顺序。↗05找到资料，并确认资料仍然有效词法与语义索引、网络搜索、语言服务和宿主知识包。↗06保存会话，也管理记忆的来源和版本候选激活、语义刷新、命名空间、转录分页和前缀分支。↗07让并行任务遵守同一套预算子智能体、Worker、优先队列、程序目录和可恢复工作流。↗08接入高级能力时，保留证据和授权状态图、发布合同、Agent Protocol、评估、类型化决策、S3 与遥测。↗09从原始记录判断任务停在哪里事件分页、资源状态、错误分类与恢复检查。↗

阅读与验证范围

这些章节依据当前 9.1.6 工作树，源码链接指向 main。能力索引与源码集合通过自动检查保持一致，链接和文档构建单独验收。这不等同于所有 provider、feature 与外部服务都经过实机验证。

十二章终端教程配有完整参考工程，已通过编译、固定模型的集成测试和离线终端操作回归。它覆盖读取、指定请求的批准与拒绝、业务提问、取消、会话恢复和过期计划拒绝；具体命令见收尾与交付。真实模型、外部租约恢复和实际服务凭据仍需按目标环境另外验收。
